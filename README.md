# 実績紹介｜面接用資料 Web版

元資料：実績紹介_4枚_面接用_配色統一版.pptx。
全4ページ、元の16:9比率・ページ順を維持。本文・数値・図・配色は元の表示内容を使用。
背景は共通ソース Design Temp_Web_Template.html の1ページ目（表紙用）と2〜4ページ目（本文用）。表紙用背景は前回の確認済み画像、本文用背景は元テンプレートから抽出したSVGを画像化して使用（横長画面への拡縮時の余白を防ぐため）。

## 使い方
index.html をブラウザで開きます。インストールやネット接続は不要です。
右下の「戻る」「次へ」、または左右矢印／PageUp／PageDown／Home／Endで移動します。
「文字を編集」を押し、文字をクリックして編集します。改行はEnter、全角日本語も入力できます。
「HTMLを保存」で全4ページの編集内容・背景・プログラムを1つのHTMLに保存します。
保存したHTMLを再度開くと、編集内容が残り、引き続き編集できます。
枠を超えた場合は文字量・改行を調整してください。自動でページを分割・追加しません。
ブラウザ内の補助保存も行いますが、端末やブラウザを変えると引き継がれません。HTMLの保存を推奨します。
「元資料の文章に戻す」は全ページの文字を元に戻します。実行前に必要な編集済みHTMLを保存してください。

## 公開資料の更新
ブラウザでの編集やHTML保存は、公開URLを更新しません。
編集済みHTMLをリポジトリの index.html に反映し、mainへコミットして再公開してください。
※build.py は shell.html を元に index.html を再生成します。編集済みHTMLを直接差し替えた後に実行すると、その変更を上書きします。ソースを継続管理する場合は編集内容を shell.html にも反映してください。

## 構成
- index.html：背景・CSS・JavaScriptを内包した完成HTML
- shell.html：編集前の本文・図・初期値
- styles.css：表示、共通背景、印刷、編集UI
- script.js：ページ移動、文字編集、保存
- build.py：単体HTMLの再生成（python build.py）
- assets：原資料の図と共通背景
- source-text.json：画面本文・元の座標。検証用

発表者ノートやコメント、元のPowerPointは公開ソースに含めていません。
本文とノートの相違は統合せず、画面本文の表記を維持しています。
元の装飾用ページ番号は共通ページネーション 1 / 4〜4 / 4 に置き換えています。
文字は画像化せず、編集可能です。フォントファイルは含めず、端末の日本語フォントを使用するため、端末により字形・折り返しに差が出ることがあります。
noindex と robots.txt で検索エンジンに非掲載を依頼していますが、URLはパスワードなしで誰でも閲覧できる通常公開です。
